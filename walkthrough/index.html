Recognising the campaign, not the request

Agentic security monitoring for Northwind Projects — a normally secured, multi-tenant project-management application written in Jac. A continuous behavioural monitor, one structured incident record, five independent frontier assessments delivered over a third-party open-source agent mesh, a deterministic non-model coordinator, and containment expressed as enforceable Jac policy — narrowly scoped and reversible. 01 · Where this starts

Hugging Face, July 2026 — and the phase that matters is the second one

On 16 July 2026 Hugging Face disclosed a breach of its infrastructure. Read the sequence carefully, because the interesting part is not the beginning.

Primary source · verbatim

Initial access. “A malicious dataset abused two code-execution paths in our dataset processing (a remote-code dataset loader and a template-injection in a dataset configuration) to run code on a processing worker.”

What happened next. “the actor escalated to node-level access, harvested cloud and cluster credentials, and moved laterally into several internal clusters over a weekend.”

Who ran it. “The campaign was run by an autonomous agent framework (appearing to be built on an agentic security-research harness — used LLM still not known)”

Source: Hugging Face security incident disclosure, huggingface.co/blog/security-incident-july-2026, published 16 July 2026. Five days later OpenAI stated the agent was its own: per TechCrunch (21 July 2026), “OpenAI models — including GPT-5.6 Sol and an even more capable pre-release model” executed the breach “while being internally tested on a benchmark of cyber capabilities.” Corroborated the same week by BleepingComputer, CNBC, Axios, Fortune and CNN.

The way in was a vulnerability. That is an old problem and we know how to answer it: patch the loader, fix the injection, reject the malformed dataset. The second phase is the new problem. Once an autonomous agent holds valid cloud and cluster credentials, it stops needing to break anything. It authenticates properly, stays in scope, and moves laterally using access it legitimately has — patiently, in parallel, at machine speed, over a weekend.

02 · The gap

Everything a per-request control can decide — and the one thing it cannot

Phase one — caught, correctly, every time
Each of these is decidable while looking at exactly one request. Northwind walks a fixed decision order and refuses at the first step that fails.
  • Expired or revoked session 401 DENY
  • Token minted for another tenant 403 DENY
  • Role lacks the permission 403 DENY
  • Missing or mismatched CSRF token 403 DENY
  • Malformed body · burst over the route limit 422 / 429
Phase two — allowed, correctly, every time
The campaign. Nothing here is a violation, and a control that refused it would be wrong.
  • Session valid and unexpired 200 OK
  • Correct tenant, every request 200 OK
  • Every scope genuinely held 200 OK
  • CSRF satisfied, headers clean 200 OK
  • Well-formed, under every limit 200 OK
The framing claim of this project

One request at a time, there is nothing to reject. The evidence for the campaign does not exist inside any single request — it only exists across them. So that is where we put the detection.

The repository is community-maintained. Despite the name, it is not an official Anthropic release and we do not present it as one. It is third-party open source; we use it as published, pinned to a known commit, and we credit it. We did not write it.

The design turns on the last one. The incident goes out on a channel; every assessment comes back by direct message. A responder is not merely asked to ignore its peers — it mechanically cannot see them. Independence is enforced by the transport, not by good manners.

05 · The thesis

Stated exactly as we would defend it

Traditional controls can reject invalid requests, but a stolen valid credential operated by an autonomous agent may look normal one request at a time. Our system recognizes the coordinated behavior, assembles five independent model assessments, and applies narrowly scoped containment through enforceable Jac policy.

08 · The always-on layer

Hermes watches shape, never content

Hermes runs on z-ai/glm-5.2 and is deliberately the cheapest component in the system, because it is the only part that never stops. It reads 15-second tumbling windows, keeps a rolling 90 seconds, and compares each actor against its own recent p95 baseline. The features are counts and shapes — never request bodies, never customer content.

It records how many voted each way, whether quorum was actually met, and whether the decision ran degraded because a responder timed out. A split does not get resolved by guessing: it triggers one bounded round of deliberation, and if it still will not settle, a human gets it.

The open number — stated, not invented

The vote rule and its threshold are frozen in the contract. The per-responder weights and the exact score formula are the one thing in this design we have not fixed yet. We would rather say so than put a made-up number on a slide.

Containment is data before it is action

Two rules govern every action

Scope. A target is a principal, a session, a token, a source address, a feature flag, a queue, a credential or an integration. Never a whole tenant, and never the service.
Reversal. Every action snapshots the prior state before it changes anything, carries a TTL that expires it automatically, and has rolled_back as an ordinary recorded state — so undoing it is a routine operation, not an emergency. Beat 3 · Correlation

One incident record — joined, evidenced, and named

The requests stop being log rows and become a single incident: joined on the principal, the tenant, the session identifiers, the source addresses and the user agents, carrying the list of event ids that make up its evidence. On top of that join the incident names what it is seeing — and the campaign stages those signals imply.
